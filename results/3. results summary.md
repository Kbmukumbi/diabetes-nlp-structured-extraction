# Results Summary — Diabetes NLP Structured Extraction Project

This folder contains the final evaluation outputs for the ClinicalBERT-based
relation extraction model trained on the i2b2 medication dataset.

---

##  1. Overall Model Performance

The model shows strong and stable performance:

- **Validation Accuracy:** 94.3%
- **Test Accuracy:** 94.38%
- **Macro F1-score:** ~0.94 on both validation and test sets
- **Loss:** ~0.21 (val), ~0.20 (test)

These metrics indicate:
- The model is not overfitting.
- It generalizes well to unseen clinical notes.
- It captures medication–relation patterns consistently.
